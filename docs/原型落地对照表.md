## 二、设计令牌对照（核心改动）

### 2.1 品牌色：暖砖红 → 青碧

| 令牌 | 落地前 | 落地后 |
|---|---|---|
| `--brand`（原 `--accent`） | `#ff5139`（hue 30，chroma 0.24） | `oklch(0.552 0.098 197)`（chroma 0.098） |
| `--brand-2` | `#ff7a5c` | `oklch(0.622 0.086 203)` |
| `--brand-3` | — | `oklch(0.706 0.064 210)` |
| `--brand-ink` | `#fff` 硬编码 | `oklch(0.995 0.002 200)` |
| `--brand-text`（新增） | — | 深色 `oklch(0.800 0.068 203)` / 浅色 `oklch(0.444 0.106 197)` |

### 2.2 语义色重排（避免与品牌青碧撞色）

| 令牌 | 落地前 | 落地后 | 原因 |
|---|---|---|---|
| `--ok` | `#34d399`（hue 165） | `oklch(0.545 0.098 145)` | 165 与青碧 197 太近，拉开到翠绿 |
| `--info` / `--blue` | `#60a5fa`（hue 248） | `oklch(0.535 0.098 262)` | 248 与青碧太近，拉开到靛蓝 |
| `--teal` | `#2dd4bf`（hue 195） | `oklch(0.545 0.078 215)` | 195 几乎与品牌同色，改为靛青 |
| `--violet` | `#8b7cf6`（hue 290） | `oklch(0.525 0.095 300)` | 微调，保持 L3 层色辨识度 |
| `--warn` | `#fbbf24` | `oklch(0.605 0.102 75)` | 保持暖黄，chroma 降饱和 |
| `--err` | `#f87171` | `oklch(0.530 0.128 26)` | 保持红，chroma 降饱和 |

### 2.3 新增前景色令牌（双主题对比度保障）

7 组 `--*-text`，浅色主题自动加深、深色主题自动提亮，实测均过 4.5:1：

```
--brand-text  --ok-text  --warn-text  --err-text
--info-text   --violet-text  --teal-text
```

**约定**：色块底 / 边框 / 图表 / 指示灯 → 用 `--brand` `--ok` 等；
文字 / 图标前景 → **必须** 用 `--*-text`。
违反会出现「浅色主题下语义色文字糊成一片」（对比度实测只有 2:1）。

### 2.4 圆角：18px 单一值 → 6 档刻度

| 令牌 | 值 | 用途 |
|---|---|---|
| `--r-xs` | 4px | 徽标、代码、日志级别标签 |
| `--r-s` | 6px | 小按钮、选项卡、KV 行 |
| `--r-m` | 8px | 按钮、输入框、日志行、字号开关 |
| `--r-l` | 12px | 卡片、面板、工具条 |
| `--r-xl` | 16px | 大卡片、更新页 logo |
| `--r-2xl` | 20px | 顶栏容器（原型用，项目顶栏贴边直角） |
| `--r-pill` | 999px | 药丸标签、开关、进度条 |
| `--r-bar-foot` | 2px | 柱状图底角（刻意近直角，让柱子"站住"） |

全仓零裸数值，由 `test:skin` 的「无裸 border-radius」断言硬拦。

### 2.5 字体：系统栈（禁止艺术字体）

| 令牌 | 值 |
|---|---|
| `--font-sans` | `system-ui, -apple-system, "Segoe UI", "Microsoft YaHei", "PingFang SC", …, sans-serif` |
| `--font-mono` | `ui-monospace, "Cascadia Mono", Consolas, "SF Mono", Menlo, monospace` |
| `--font-num` | `var(--font-sans)`（数值仅靠 `tabular-nums` 对齐，不引特殊字体） |

替换掉原 `"Cascadia Code","Consolas","Courier New"` 硬编码族名，统一走令牌。

### 2.6 缓动：回弹 → 指数缓出

| 令牌 | 落地前 | 落地后 |
|---|---|---|
| `--trans` | `cubic-bezier(.34,1.25,.4,1)`（**带回弹**） | `cubic-bezier(0.25,1,0.5,1)`（指数缓出） |
| `--dur-*` | 仅 `--dur: .22s` | 四档：instant 110 / fast 160 / base 220 / slow 380 |

回弹缓动会让 UI 显得"廉价"，指数缓出更克制专业。

## 四、兼容性处理

```css
--accent:   var(--brand);
--accent-2: var(--brand-2);
--radius:   var(--r-l);
--radius-s: var(--r-l);
--trans:    var(--ease-out-quart);
```

`.ghost`（等价 `.btn-ghost`）、`.mini`、`.hd-note`、`.kv` 两种形态并存。

## 五、验证

| 命令 | 覆盖 | 结果 |
|---|---|---|
| `npm run test:skin` | 换肤 13 项（含波纹行为实跑） | 13 / 0 |
| `npm run test:all` | 全套 223 项 | 223 / 0 |
| `npm run test:tokens` | 原型 CSS 变量引用完整性 | 通过 |
| `npm run test:proto` | 原型 12 文件交互 + 令牌契约 | 通过 |

`test:skin` 的关键设计：**断言行为而非元素存在**。
例如「派发 `pointerdown` 后 `--rx`/`--ry` 真的被写入按钮样式」——
只断言"按钮有波纹样式"会漏掉"JS 从未绑定"这类静默失效。
