面板同时是检索 API 网关，守护进程与 MCP 都从这里读数据。
第一次使用，Agent 怎么连？ 分两种，装一次就永久生效，之后每次对话都不用管：
  1. 后台自动（推送 + 注入）：守护进程启动后自动处理，采集各 Agent 的会话增量上传记忆库，无需任何配置。登录自启用 node register-all.cjs --autostart。
  2. MCP 安装（Agent 主动检索）：跑一次 node register-all.cjs，会自动把记忆工具写进本机所有支持 MCP 的客户端配置（ZCode / Claude Code / Cursor / Codex），并追加全局指令文件。之后每个新会话自动携带记忆工具，模型需要时自主调用。
Claude Code 还会注入 UserPromptSubmit hook：每次提问前自动检索相关记忆并注入上下文（真正无感，不依赖模型主动调用）。首次使用时客户端会提示「信任」该 hook，点一次即可。
