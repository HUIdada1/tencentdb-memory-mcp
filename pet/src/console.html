记忆库连接

保存即写入 ~/.zcode/tdai-mcp.json（原文件备份为 .bak）。后台守护、MCP 工具、hook 注入共用这一份配置，改完立即生效。

第一次使用：Agent 怎么连？

装一次就永久生效，之后每次对话都不用手动指定任何东西：
  1. 后台自动（推荐，无需额外配置）：本应用已内置后台守护——运行期间自动采集各 Agent 的会话增量上传到记忆库，并在本机 127.0.0.1:8100 提供记忆检索服务。关闭窗口后仍在托盘后台运行，配合「开机自启」即全程无感。
  2. MCP 接入（让 Agent 主动检索）：点「一键接入」，把 tdai 记忆工具写进本机已安装客户端（ZCode CLI / Claude Code / Cursor / Codex）的配置，并追加全局指令文件。之后每个新会话自动携带记忆工具，模型需要时自主调用。
  3. Claude Code hook：一键接入会同时注入 UserPromptSubmit hook——每次提问前自动检索相关记忆并注入上下文，不依赖模型主动调用。首次使用时 Claude Code 会提示「信任」，点一次即可。
接入目标是本程序自身（不需要安装 Node，也不需要源码目录）。未安装的客户端会自动跳过。
